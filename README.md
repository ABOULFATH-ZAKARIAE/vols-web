## Getting started

### Prerequisites

Node.js 24 (see `.nvmrc`) and npm.

### Setup

```bash
git clone [TODO: repo URL]
cd vols-web
npm install
cp .env.example .env.local   # then fill in real values
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command                 | What it does                          |
| ----------------------- | ------------------------------------- |

| `npm run lint`          | Lint the code                         |
| `npm run typecheck`     | Check types                           |
